# Protótipos

Use esta pasta para experimentos pequenos de mecânica que ainda não fazem parte do jogo integrado. Cada protótipo deve ter uma nota com objetivo, como executar, estado, limitações e responsável combinado.

Quando um protótipo for aprovado para integrar, abra uma tarefa/branch e mova ou reimplemente o conteúdo em `game/`, após revisão. Não use assets gerados por IA.
