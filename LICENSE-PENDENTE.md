# Licença a definir

A equipe ainda não escolheu uma licença para este repositório. Não apresentar o projeto como licenciado enquanto essa decisão não for tomada.

Antes de criar um arquivo `LICENSE`, combinar:

1. Se a licença cobre apenas o código ou também roteiro, arte, áudio e outros materiais.
2. Se todos os autores concordam com a licença e com a publicação.
3. Como serão respeitadas licenças de materiais de terceiros.

Até essa decisão, todos os direitos permanecem com seus respectivos autores. Este aviso é informativo e não substitui orientação jurídica.
