# Assets

Guarde aqui arte, áudio, fontes e outros materiais aprovados para o jogo. Combine subpastas com a equipe quando os primeiros arquivos forem adicionados.

Para cada asset, registre em um arquivo de créditos:

- nome/descrição e caminho;
- autor ou fonte;
- licença e link para os termos;
- alterações feitas;
- integrante que verificou a permissão.

Use apenas material produzido pela equipe ou cujo uso no projeto esteja permitido. O acordo da reunião proíbe assets produzidos por IA generativa e templates feitos com IA. Não inclua materiais sem autorização.
