# Projeto Ren'Py

Esta pasta receberá os arquivos gerados pelo launcher do Ren'Py. O projeto ainda não foi criado neste repositório.

## Quando iniciar

1. Uma pessoa da equipe cria um projeto pelo launcher Ren'Py.
2. A equipe combina a versão da engine e registra aqui como executar o projeto.
3. Copia os arquivos do projeto para esta pasta, preservando sua estrutura padrão.
4. Revisa `.gitignore` para não enviar cache, saves locais ou builds grandes.

Não coloque senhas, tokens, dados pessoais ou assets sem licença nesta pasta.
